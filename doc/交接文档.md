# ISACPlayer 工程交接文档 (Handover Document for Codex)

## 1. 项目概述与架构定位

- **项目名称**：ISACPlayer
    
      
    
- **项目定位**：一款兼具 **Apple Music 消费级视听交互美学** 与 **DAW / PipeWire (coppwr) 工业级流式音频处理内核** 的模块化数字音频播放器。
    
      
    
- **目标平台**：Linux (Arch Linux / Wayland / ALSA / PipeWire 首发)，后续扩展 Windows / macOS。
    
      
    
- **技术栈**：C++20、Qt 6 (Widgets / GraphicsView)、miniaudio (单头文件音频后端)、TagLib (元数据解析)。
    
      
    

## 2. 核心技术架构与工程铁律

### 2.1 双世界解耦与实时线程安全

1. **双图热替换 (Twin-Graph Swap)**：
    
      
    - **UI 线程**负责画布交互、连线、环路校验（Kahn 拓扑排序）并编译出只读的 `ExecutionPlan`。
        
          
        
    - 通过 `std::atomic<std::shared_ptr<ExecutionPlan>>` 指针原子替换，实现正在听歌时拖拽/拔插连线 **零爆音、零挂起、无锁热切换**。
        
          
        
2. **实时音频线程铁律**：
    
      
    - 位于 `AudioEngine::renderAudio` 及所有节点 `process()` 中。
        
          
        
    - **绝对禁止**：调用 `malloc` / `new` / `free`、使用 `std::mutex`、发起磁盘/网络 I/O、或直接触发 Qt 信号槽。
        
          
        
3. **全链路高精度浮点总线**：
    
      
    - 内部流经节点的信号统一采用 **64-bit Double Planar (非交错)** 内存排布 (`AudioBuffer64`)，确保多级级联计算时精度无损。

## 4. 插件管理系统规范 (Plugin System)

为了支持类似 foobar2000 的第三方动态库扩展，系统设计了标准 C++ Qt 插件契约接口 (`IAudioPlugin`)：

  

- **接口核心要素** (`IAudioPlugin.h`)：
    
      
    1. `pluginName()` / `author()` / `description()`：元数据与当前信息显示。
        
          
        
    2. `numInputs()` / `numOutputs()` / `inputName()` / `outputName()`：端口与针脚动态声明。
        
          
        
    3. `process(inBus, outBus, frames)`：实时音频线程计算函数。
        
          
        
    4. `createControlWidget(QWidget* parent)`：导出原生 Qt 控件，供主界面的右侧属性检视器（Inspector）动态嵌入。
        
          
        
- **自动加载机制**：程序启动时通过 `QPluginLoader` 扫描运行目录下的 `plugins/` 文件夹自动注册算子。
    
      
    

## 5. 待实现的十大数据处理算子 (Modules to Implement)

|**序号**|**模块名称 (Module)**|**端口规范**|**核心功能与技术指标**|
|---|---|---|---|
|**1**|**Basic 2I1O Adder**|2 输入 / 1 输出|基础混音算子，波形点对点相加，带削波防爆限幅。|
|**2**|**Basic 2I1O Multiplier**|2 输入 / 1 输出|幅度缩放算子，用于音量增益调节或信号交叉调制。|
|**3**|**ReplayGain Node**|2 输入 / 2 输出|回放增益平衡器，根据标签动态调整响度，内置真峰值前瞻软限制器。|
|**4**|**Biquad Equalizer Node**|2 输入 / 2 输出|10 段参量 EQ（RBJ 双二阶滤波器），支持高架/低架/峰值/陷波。|
|**5**|**Stereo Widener Node**|2 输入 / 2 输出|中侧矩阵（M/S Matrix）声场拓宽器，无相位失真增强空间包围感。|
|**6**|**Convolution Reverb Node**|2 输入 / 2 输出|载入 `.wav` 脉冲响应（IR），频域快速卷积模拟物理空间混响。|
|**7**|**Visualizer Tap Node**|2 输入 / 2 输出|纯旁路侦听算子，通过 SPSC 环形队列异步投递 PCM 数据驱动 FFT 频谱和 VU 表。|
|**8**|**ABX Comparator Node**|4 输入 / 2 输出|双盲测试比较器，支持无爆音瞬态切换及二项分布统计检验。|
|**9**|**Downsample & Interpolation Node**|2 输入 / 2 输出|采样率与分辨率转换算子（含抗混叠低通滤波与 Hermite 插值）。|
|**10**|**Crossover Filter Node**|2 输入 / 6 输出|4 阶 Linkwitz-Riley 高阶电子分频器，用于多路分频音箱或独立低音炮。|
